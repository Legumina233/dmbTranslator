# 模拟"新用户安装"操作手册（两条路线）

> 目的：在一台**看起来什么都没有**的机器上，验证「跑一次 `setup.cmd` → 浏览器加载扩展 → 直接可用」。
> 关键：**把你机器上"已经替你准备好"的东西藏起来**，否则会自动命中，测出假通过。

## 0. 公共准备（两条路线都要）

```powershell
# ① 停掉正在跑的本机服务（否则 11436/11437 被占用，副本起不来会误判失败）
#    关掉 start_server.cmd / start_ollama.cmd 的窗口，或：
Get-Process pythonw,python -ErrorAction SilentlyContinue | Where-Object { $_.Path -like "*dmbTranslatorV2\.venv*" } | Stop-Process -Force

# ② 备份并藏起"自动装好的 Python/Node"（★ 最关键的一步）
Move-Item "<副本>\.tools" "<副本>\.tools_bak" -ErrorAction SilentlyContinue

# ③ 当前会话做成"干净环境"
Remove-Item Env:\DMB_PYTHON,Env:\DMB_OLLAMA_EXE,Env:\OLLAMA_MODELS -ErrorAction SilentlyContinue
# 注意：**不要动 PATH** —— 把 PowerShell 自己踢出去会让脚本里的下载/解压全部失败（真实用户也不会有这种 PATH）

# ④ 浏览器里移除旧的 dmbTranslator 扩展（测试只加载副本里的 dist-chromium）
#    chrome://extensions → 找到 dmbTranslator → 移除
```

## A. Release 路线（下载完整包）

```powershell
# ① 出包（已由维护者生成：E:\AI\dmbTranslatorV2\artifacts\dmbTranslator-0.6.6-win64.zip）
# ② 解压到空目录
Expand-Archive E:\AI\dmbTranslatorV2\artifacts\dmbTranslator-0.6.6-win64.zip -DestinationPath G:\dmb
# ③ 跑（到 [7/7] 直接回车；它会探测 Ollama 并 setx 记住）
cd G:\dmb ; .\setup.cmd
```

## B. 源码克隆路线

```powershell
# ① 源码包（已由维护者生成：artifacts\dmbTranslator-0.6.6-src.zip ← 只含 git 跟踪的文件）
Expand-Archive E:\AI\dmbTranslatorV2\artifacts\dmbTranslator-0.6.6-src.zip -DestinationPath G:\src
# ② 跑
cd G:\src ; .\setup.cmd
```

## 验收清单

```
□ setup.cmd 结束 exit=0，全程无 [FAIL]
□ <副本>\.tools\python311\python.exe 出现（自动装了 Python）
□ <副本>\.venv\pyvenv.cfg 的 home 指向上面那个 python311（环境自包含）
□ <副本>\frontend\apps\extension\dist-chromium\manifest.json 版本=0.6.6 且 content.js 存在
□ <副本>\run\nm_host_launcher.exe 存在；install_native_host.py 打印"自校验通过"
□ netstat 见 11436/11437，且 Get-Process 路径 = <副本>\.venv\Scripts\python(w).exe
□ .venv\Scripts\python.exe scripts\test_ocr.py 通过
□ chrome://extensions 加载 <副本>\dist-chromium → 版本 0.6.6、弹窗按钮可点、能起停服务/Ollama
```

## 收尾（必须做，否则会打乱你本机）

```powershell
# ① 恢复藏起来的工具目录
Move-Item "<副本>\.tools_bak" "<副本>\.tools" -Force
# ② 重新用 E: 那份注册宿主（否则弹窗按钮指向已删除的测试副本）
& E:\AI\dmbTranslatorV2\.venv\Scripts\python.exe E:\AI\dmbTranslatorV2\scripts\install_native_host.py
# ③ 重新加载 E: 那份扩展：chrome://extensions → 加载已解压 → E:\AI\dmbTranslatorV2\frontend\apps\extension\dist-chromium
# ④ 重新起服务：scripts\start_server.cmd / scripts\start_ollama.cmd
```

## 已知"测不准"的干扰项

| 干扰 | 影响 | 处理 |
|---|---|---|
| `<副本>\.tools` | 直接命中已装好的 Python/Node（假通过） | 公共准备 ② 藏起来 |
| 浏览器里的旧扩展 | 测不到"从零加载" | 公共准备 ④ 移除 |
| 旧宿主注册 | `[6/6]` 会覆盖成测试副本 | 收尾 ② 重新注册 |
| pip / npm 缓存 | 下载比真用户快 | 可接受；只要联网步骤确实跑过 |
| Ollama 与模型 | 前提假设"已装好" | 保持它在跑即可；`[7/7]` 只探测不代装 |
